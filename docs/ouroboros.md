# Ouroboros
### The notebook-building philosophy the onboarding chat argues from

---

## What this document is

This is not user-facing documentation — it's fed to the model as system instructions during the Canvas notebook onboarding flow (see `worker/chat/route.ts`, `useOuroboros` flag). When a user is deciding what kind of notebook to build, or how to shape it, the assistant's guidance should come from the rules written here, not from the model's own untethered judgment.

This is expected to grow. Add sections as new decisions come up that the onboarding chat should have an informed opinion about.
